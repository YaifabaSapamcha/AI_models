- Testing model performance on everyday computer hardware

## Getting started

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
cd YOUR-REPOSITORY
```

Then enter the folder for the project you want to try. For example:

```bash
cd "Stream_Webcam_Detections"
```

Follow the instructions in that folder's README file. Most of the projects can be started with a virtual environment:

### Windows

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

### Linux or macOS

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Not every project uses the same dependencies, so install the requirements from the selected project folder rather than from the repository root.
